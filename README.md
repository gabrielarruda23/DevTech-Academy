DevTech Academy — Sistema de Gerenciamento de Alunos

Sistema simples de **cadastro, edição, exclusão e relatórios** de alunos, feito com **HTML, TailwindCSS e JavaScript** (orientado a objetos).

---
Funcionalidades

-  Cadastrar, editar e excluir alunos
-  Exibir lista dinâmica de alunos em tabela
-  Armazenamento local via `localStorage`
-  Relatórios automáticos:
  - Alunos aprovados (nota ≥ 7)
  - Média das notas
  - Média das idades
  - Ordem alfabética
  - Quantidade por curso
